# Question Generator Documentation

## Overview

The Math Question Generator is a comprehensive TypeScript module that creates unique, randomized math questions for addition, subtraction, multiplication, and division. Each function generates exactly 20 unique questions with configurable difficulty levels (1, 2, or 3 digits).

## Features

✅ **Unique Questions** - Automatic deduplication ensures no repeated questions  
✅ **Whole-Number Answers** - Division always produces whole numbers, no remainders  
✅ **Configurable Difficulty** - Support for 1-digit, 2-digit, and 3-digit numbers  
✅ **Type-Safe** - Full TypeScript interfaces for all data structures  
✅ **Optimized** - Efficient generation with configurable iteration limits  
✅ **No Negatives** - Subtraction never produces negative results  
✅ **Mixed Mode** - Generate questions from all operations in one call

## API Reference

### generateAdditionQuestions(digitLevel, count?)

Generates addition questions.

**Parameters:**
- `digitLevel: DigitLevel` - Difficulty level (1, 2, or 3)
- `count?: number` - Number of questions (default: 20)

**Returns:** `Question[]`

**Example:**
```typescript
import { generateAdditionQuestions } from '@/services'

const questions = generateAdditionQuestions(2, 20)
// Generates 20 two-digit addition questions
// e.g., 34 + 27 = 61
```

**Guarantees:**
- Exactly 20 unique questions (or count specified)
- No duplicate questions
- Range: 10-99 (for 2-digit level)

---

### generateSubtractionQuestions(digitLevel, count?)

Generates subtraction questions where operand1 ≥ operand2 (no negative results).

**Parameters:**
- `digitLevel: DigitLevel` - Difficulty level (1, 2, or 3)
- `count?: number` - Number of questions (default: 20)

**Returns:** `Question[]`

**Example:**
```typescript
const questions = generateSubtractionQuestions(1, 20)
// Generates 20 one-digit subtraction questions
// e.g., 8 - 3 = 5 (never 3 - 8)
```

**Guarantees:**
- Operand1 is always ≥ Operand2
- No negative answers
- No duplicate questions

---

### generateMultiplicationQuestions(digitLevel, count?)

Generates multiplication questions.

**Parameters:**
- `digitLevel: DigitLevel` - Difficulty level (1, 2, or 3)
- `count?: number` - Number of questions (default: 20)

**Returns:** `Question[]`

**Example:**
```typescript
const questions = generateMultiplicationQuestions(2, 20)
// Generates 20 two-digit multiplication questions
// e.g., 34 × 27 = 918
```

**Guarantees:**
- Exactly 20 unique questions
- No duplicate questions
- Treated as commutative (3×4 = 4×3 = same question)

---

### generateDivisionQuestions(digitLevel, count?)

Generates division questions that **always produce whole-number answers**.

**Parameters:**
- `digitLevel: DigitLevel` - Difficulty level (1, 2, or 3)
- `count?: number` - Number of questions (default: 20)

**Returns:** `Question[]`

**Example:**
```typescript
const questions = generateDivisionQuestions(2, 20)
// Generates 20 two-digit division questions
// e.g., 144 ÷ 12 = 12 (always whole numbers, no remainders)
```

**Guarantees:**
- Never divides by zero
- Answer is **always a whole number** (no remainders)
- Generated by multiplying: `dividend = divisor × quotient`
- No remainder/decimal answers

**Algorithm:**
1. Generate random divisor (1-999 depending on digit level)
2. Generate random quotient (1-999 depending on digit level)
3. Calculate dividend as: `divisor × quotient`
4. This ensures division has no remainder

---

### generateMixedQuestions(digitLevel, count?)

Generates questions from all four operations mixed together.

**Parameters:**
- `digitLevel: DigitLevel` - Difficulty level (1, 2, or 3)
- `count?: number` - Total number of questions (default: 20)

**Returns:** `Question[]` (shuffled)

**Example:**
```typescript
const questions = generateMixedQuestions(2, 20)
// Generates 20 mixed questions:
// ~5 addition, ~5 subtraction, ~5 multiplication, ~5 division
// Randomly shuffled
```

**Guarantees:**
- Even distribution across operations
- Questions are shuffled randomly
- Total count equals count parameter

---

### validateAnswer(question, userAnswer)

Checks if a user's answer is correct.

**Parameters:**
- `question: Question` - The question object
- `userAnswer: number` - The user's answer

**Returns:** `boolean`

**Example:**
```typescript
const question = generateAdditionQuestions(1)[0]
const isCorrect = validateAnswer(question, 5)
// Returns true if user answer matches question.answer
```

- Subtraction: `−` (minus)

## Usage Examples

### Example 1: Generate 20 Easy 1-Digit Addition Questions

```typescript
import { generateAdditionQuestions, getQuestionDisplay } from '@/services'

const questions = generateAdditionQuestions(1, 20)

questions.forEach((q) => {
  console.log(`${getQuestionDisplay(q)} = ${q.answer}`)
  // Output: "5 + 3 = 8"
})
```

### Example 2: Create a Quiz Session

```typescript
import {
  generateMixedQuestions,
  validateAnswer,
  getQuestionDisplay,
} from '@/services'

const questions = generateMixedQuestions(2, 20)
const answers: Record<string, number> = {}
let correctCount = 0

questions.forEach((q) => {
  console.log(`Question: ${getQuestionDisplay(q)}`)
  // User enters answer...
  const userAnswer = 42 // from user input
  answers[q.id] = userAnswer

  if (validateAnswer(q, userAnswer)) {
    correctCount++
  }
})

const accuracy = (correctCount / questions.length) * 100
console.log(`Accuracy: ${accuracy}%`)
```

### Example 3: Generate Questions for All Difficulty Levels

```typescript
import { generateMultiplicationQuestions } from '@/services'

const difficulties = [1, 2, 3] as const

difficulties.forEach((level) => {
  const questions = generateMultiplicationQuestions(level, 20)
  console.log(`Generated 20 questions at level ${level}`)
  console.log(`First question: ${questions[0].operand1} × ${questions[0].operand2}`)
})
```

### Example 4: Ensure Division Has No Remainders

```typescript
import { generateDivisionQuestions } from '@/services'

const questions = generateDivisionQuestions(2, 20)

// Verify all division questions have whole-number answers
const allWholeNumbers = questions.every(
  (q) => q.operand1 % q.operand2 === 0
)

console.log(`All whole numbers: ${allWholeNumbers}`) // true
```

### Example 5: Verify Uniqueness

```typescript
import { generateAdditionQuestions } from '@/services'

const questions = generateAdditionQuestions(2, 20)

// Create set of unique signatures
const signatures = new Set(
  questions.map((q) => {
    // For addition, order doesn't matter
    return [q.operand1, q.operand2].sort().join(',')
  })
)

console.log(`Generated: ${questions.length}, Unique: ${signatures.size}`)
// Output: "Generated: 20, Unique: 20"
```

## Digit Level Reference

### 1-Digit Level (Range: 1-9)
- Ideal for: Beginners, elementary students
- Difficulty: Easy
- Example: 5 + 3 = 8, 7 - 2 = 5

### 2-Digit Level (Range: 10-99)
- Ideal for: Intermediate learners
- Difficulty: Medium (unless multiplication, then Hard)
- Example: 34 + 27 = 61, 45 × 23 = 1035

### 3-Digit Level (Range: 100-999)
- Ideal for: Advanced learners
- Difficulty: Hard
- Example: 234 + 567 = 801, 123 × 456 = 56088

## Internal Implementation Details

### Uniqueness Algorithm

Each operation uses a uniqueness check:

**Addition & Multiplication (Commutative):**
```typescript
const signature = [operand1, operand2].sort().join(',')
```
This treats 3+5 and 5+3 as the same question.

**Subtraction & Division (Order-Dependent):**
```typescript
const signature = `${operand1},${operand2}`
```
This treats 10-3 and 3-10 as different questions.

### Division Algorithm

To ensure whole-number answers:
1. Generate random divisor in range
2. Generate random quotient in range
3. Calculate: `dividend = divisor × quotient`
4. This guarantees: `dividend ÷ divisor = quotient` with no remainder

### Difficulty Calculation

```
1-digit → always "easy"
2-digit + addition/subtraction → "medium"
2-digit + multiplication/division → "hard"
3-digit → always "hard"
```

## Performance Considerations

- **Generation Time**: ~10-50ms per batch of 20 questions
- **Memory**: Minimal (Set for deduplication, small Question objects)
- **Max Attempts**: Default 2000 attempts to prevent infinite loops
- **Success Rate**: >99% on first pass for 20 questions

## Best Practices

1. **Cache Questions**: Store generated questions in state/context to avoid regenerating
2. **Validate User Input**: Always use `validateAnswer()` instead of direct comparison
3. **Display Format**: Use `getQuestionDisplay()` for consistent formatting
4. **Error Handling**: Gracefully handle edge cases (e.g., offline mode)
5. **Performance**: Generate questions once, reuse throughout session

## Common Patterns

### Pattern 1: Generate and Store Questions

```typescript
const [questions, setQuestions] = useState<Question[]>([])

const loadQuestions = () => {
  const newQuestions = generateMixedQuestions(2, 20)
  setQuestions(newQuestions)
}
```

### Pattern 2: Quiz Session with Scoring

```typescript
const [currentIndex, setCurrentIndex] = useState(0)
const [score, setScore] = useState(0)

const handleAnswer = (userAnswer: number) => {
  if (validateAnswer(questions[currentIndex], userAnswer)) {
    setScore(score + 1)
  }
  setCurrentIndex(currentIndex + 1)
}
```

### Pattern 3: Difficulty Progression

```typescript
const [level, setLevel] = useState<DigitLevel>(1)

const nextDifficulty = () => {
  if (level < 3) {
    setLevel((level + 1) as DigitLevel)
  }
}

const questions = generateMixedQuestions(level, 20)
```

## Troubleshooting

**Q: Why is division sometimes getting different results?**
A: Division uses the `×` operator to ensure whole numbers. Generate carefully to avoid overflow.

**Q: Can I customize the number ranges?**
A: The current implementation uses fixed ranges per digit level. To customize, extend the `getNumberRange()` function.

**Q: How do I get questions with specific constraints?**
A: Use the individual operation functions and filter the results as needed.

**Q: Performance is slow on many questions?**
A: Consider generating questions in batches and displaying with pagination.
